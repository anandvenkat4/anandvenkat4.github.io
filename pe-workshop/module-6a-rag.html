RAG — stop the model inventing things

This morning a model invented "Policy 4.2" and then approved its own citation. RAG is the practical fix: don't ask the model to remember — hand it the text.
Start here · the callback

You already saw why this matters

In Module 3, self-critique produced a confident, well-written, fabricated policy reference — and then certified it as correct. No amount of clever prompting fixes that, because the model cannot check a fact it does not have.

Retrieval-Augmented Generation changes the question from "what do you remember?" to "what does this passage say?" — which a model is genuinely good at.

Lab 7 · 45 minutes

Build a tiny RAG over your own text

  • Take 3–5 short documents. Split them. Retrieve by keyword — no vector database needed.
  • Done = five questions answered with citations, including one question the documents cannot answer, correctly refused.
  • Break it: ask something adjacent but uncovered and see whether it refuses or drifts.
  • Stretch: verify every claim against the source automatically.
