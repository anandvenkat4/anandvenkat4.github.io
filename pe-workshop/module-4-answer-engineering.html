Answer engineering — output your code can trust

A correct answer in the wrong shape is a failed answer. This module is about controlling what comes back, and refusing to trust it until it has been checked.
Start here · the 3am failure

The model was right. The pipeline still broke.

Your extractor ran happily for three weeks. Then one invoice came back as ```json { "total": 56640 } ``` — same data, same accuracy, wrapped in a markdown fence. JSON.parse() threw on the first character and the night's batch died.

Nobody prompted it badly. They just never specified the shape and never validated the result. Those two omissions are this whole module.

Answer shape — build the schema one constraint at a time

Toggle each constraint and watch the output change. Note where it looks fixed but still is not.

build it Five constraints that make output parseable
Name the fields, alwaysWithout names you get prose. This is the single biggest step.
Types are not optional"Rs 56,640" and 56640.00 are both "the total". Only one goes in a database.
Dates in ISO2026-03-12, never "12 March 2026". Say so explicitly or you will get both.
Say what "missing" looks likeLeft unsaid, the model writes "N/A", "unknown" or invents a value. Ask for null and forbid guessing.

Never trust it — validate, then repair

Prompting reduces malformed output. It does not eliminate it. Production extraction always has a validator, and usually a repair step:

output = call_model(prompt)
try:
    data = validate(parse(output))          # schema check, not just JSON.parse
except InvalidOutput as e:
    output = call_model(repair_prompt(output, e))   # one retry, showing the error
    data = validate(parse(output))          # fail loudly if it still breaks
Retry once, with the errorTelling the model exactly what was wrong fixes most malformed outputs on the second attempt.
Fail loudly after thatNever let an unparseable record slip through as a default or an empty object.
Log every failureThe failures are your test set — this is where Lab 8's evaluation items come from.
