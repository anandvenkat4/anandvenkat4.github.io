Agents — and what happens when a tool fails

An agent is just a model, some tools, and a loop. The prompt decides what it may use and when to stop. Everything interesting is in the failure modes.
Start here

The demo that looks like a success

You will see an agent answer a question about sales figures. It plans, it queries a database, it reasons, it answers. It looks flawless.

One of its tool calls failed halfway through. Nothing in the final answer tells you that. Step through it and find the moment.

The loop, in one line

THOUGHT▶ACTION▶ OBSERVATION▶THOUGHT▶ANSWER

This is ReAct — reason and act, interleaved (Yao et al., 2022). The model thinks, picks a tool, reads the result, thinks again. The prompt supplies the tool list, the format, and the stopping rule.

There is no magic in the word "agent". It is a while-loop with a language model inside it.

The defence: make failure loud

Say what to do when a tool fails"If a tool returns an error, say so explicitly and do not estimate the value." One sentence, most of the fix.
Cap the stepsAn unbounded loop is an unbounded bill.
Log every stepIf you cannot see the trace, you cannot debug or defend it.
Validate tool callsNever execute a tool call the model invented that is not on the allowed list.

When should it use a tool at all?

Beginners give agents too many tools and too much freedom. Half the skill is knowing when not to call one.

Multilingual prompting — quality is not uniform

The same model is not equally good in every language: training data is overwhelmingly English. Watch the quality drop, and then watch one sentence of instruction recover most of it.

compare The same task in four settings
Code-switchingThe model drifts back to English mid-answer, especially for technical terms. Name the behaviour and forbid it explicitly.
Longer output degrades fasterA one-line answer may be perfect while a paragraph falls apart.
Small local models are worseExpect a bigger gap on llama3.2 than on a hosted frontier model — worth demonstrating in the lab.
Evaluate in the target languageAn English test set tells you nothing about Tamil quality.
Lab 6 · 45 minutes

Build one agent loop, or one language comparison

Pick one. Both produce a documented artefact for your capstone.

  • Agent path: one tool, a hard step cap, and an explicit rule for what to do when the tool fails. Done = a logged trace that reaches an answer, including one deliberate tool failure you handled.
  • Language path: the same task in two languages, before and after an explicit language instruction. Done = four outputs and a short quality note.
  • Break it: remove the step cap and see how far it goes before you stop it.
