Text-based techniques — examples, boundaries, reasoning

Four levers you will use constantly: examples, delimiters, roles, and asking for reasoning. Each has a job — and each is routinely used for the wrong one.
Start here · in-context learning

The model learns from your prompt without learning anything

Put two solved examples in a prompt and the model follows the pattern. Nothing was trained, no weights changed — the examples are simply there, in the context, being imitated. That is in-context learning, and it is the mechanism behind everything in this module.

Which also tells you its limit: the pattern disappears the moment the prompt does.

Each lever has one job

Examples fix format. Delimiters fix boundaries. Roles nudge vocabulary. Reasoning fixes multi-step tasks. Using the wrong lever for a problem is the most common mistake in this course — and it is exactly what M3 pushes on.
